# Imágenes de referencia

Retratos usados como ejemplo en la etapa 2 de Aguamarina AI, para que un juez
pueda probar la experiencia sin tomarse una selfie.

|---|---|---|---|
| `ref-1.jpg` | Piel clara | Fría | Pexels · [photo 415829](https://www.pexels.com/photo/415829/) |

| `ref-3.jpg` | Piel morena | Cálida | Pexels · [photo 1239291](https://www.pexels.com/photo/1239291/) |

Las tres fueron elegidas con encuadre frontal, cuello y hombros visibles, para
que también funcionen con el probador virtual de YouCam.

Las fotos se usan bajo la [Licencia de Pexels](https://www.pexels.com/license/)
y la [Licencia de Unsplash](https://unsplash.com/license), que permiten uso
gratuito, incluso comercial.

Las paletas son ejemplos orientativos asociados a cada retrato. La imagen que
sube una persona se analiza localmente y no se envía a YouCam.
